Generated by scripts/gen_api_docs.py from rag.application.events.contracts — do not edit by hand. Every event is an eventcommon Envelope with `source: llm-rag-service` and a PascalCase `type` that is also the SNS `EventType` attribute. Payloads carry identifiers, versions and status only (EVT-7).

Consumes the six queues of §12.4 (each with its own DLQ).
